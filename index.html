경기장 지도 (카카오맵)

📍 일반구장⭐ 즐겨찾기⚽ 확정경기
⚽ 플랩풋볼에서 서울 지역 경기 찾아보기 ↗
경기장을 선택하거나 검색하면 지도에 핀이 표시됩니다.
목록에 있는 경기장은 정확한 주소로, 그 외에는 입력한 이름으로 지도에서 검색해 표시됩니다.
경기장 이름은 지도에 항상 표시되고, 웹/모바일 화면 크기에 맞게 글자 크기가 자동으로 조정됩니다.
카카오맵을 불러오지 못했습니다
이 JavaScript 키는 카카오 개발자 사이트의 "플랫폼 > Web" 설정에 등록된 사이트 도메인에서 열었을 때만 지도가 표시됩니다.
지금 이 파일을 다른 방식(로컬 더블클릭, 등록하지 않은 도메인)으로 열었다면 그것이 원인입니다.
해결하려면: developers.kakao.com → 내 애플리케이션 → 해당 앱 선택 → 플랫폼 → Web 플랫폼에 실제로 사용하실 주소를 사이트 도메인으로 등록해 주시기 바랍니다.

실시간 데이터 새로고침

다른 사람이 방금 투표했거나 관리자 도구를 다른 기기(웹/모바일/홈 화면 앱)에서 사용 중일 때, 페이지를 새로고침하지 않고 최신 데이터를 바로 가져올 수 있습니다.

경기장·시간·링크·용병 등록

확정된 경기 날짜에 경기장, 경기 시간, 경기 신청/안내 링크, 용병(게스트)을 입력하면 홈 화면 "다음 경기" 카드에 그대로 표시됩니다.
링크를 입력하면 "경기 링크" 버튼이 함께 표시되어, 눌렀을 때 해당 주소로 이동합니다.
용병은 팀원이 아니라 그 경기에 일회성으로 참여하는 인원을 이름으로 등록하는 용도입니다.

공지사항 관리

기상청 API 키 설정

지금까지 날씨는 Open-Meteo(해외 예보 모델)를 사용해서 실제 기상청 수치와 다를 수 있습니다.
아래에 기상청 API 키를 등록하면 오늘~모레 예보는 실제 기상청 단기예보 데이터로 표시됩니다(그 이후 날짜는 아직 Open-Meteo로 보완됩니다).
키 발급: data.go.kr "기상청_단기예보 조회서비스"에서 무료 활용신청 → "일반 인증키(Decoding)"를 그대로 복사하여 붙여넣으시기 바랍니다.

미투표 통계 제외 주간

시험운영 기간처럼, 팀 순위(참석·미투표·불참)에 영향이 가면 안 되는 주간을 지정합니다.
날짜를 하나 고르면 그 날짜가 속한 주(일~토) 전체가 팀 순위 집계에서 완전히 제외됩니다.

순위 횟수 수동 조정

자동 집계된 참석·미투표·불참 횟수에 더하거나 뺄 값을 입력합니다. (예: 특정 상황을 감안해 불참 1회를 빼주고 싶으면 -1) 자동 집계 위에 더해지는 방식이라, 실제 투표 기록 자체는 바뀌지 않습니다.
